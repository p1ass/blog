# p1ass の文体プロファイル

文体は題材を問わず共通とする。技術解説、参戦記、雑記のいずれでも日本語の書き方はそろえる。題材ごとに変わるのは構成だけ。

各項目は blog.p1ass.com の既存 77 記事と、note の「中古マンションを買った話」から抽出した。

## 基本

- **ですます調**。一人称は「私」
- **書き言葉で通す**。口語表現と絵文字を避ける
  - 避ける対象: 絵文字全般、「〜だな〜」「〜しちゃう」「わいわい」「やばい」「ありがたや」、副詞的な「すごい」
  - 過去記事には口語が多数あり、絵文字も 77 記事中 29 記事で使われているが、今後は書き言葉でそろえる
- 半角英数と日本語の間に半角スペースを入れる
  - 良い例: `Claude Code Action を使って PR の Code Suggestion をしてもらう`
  - 悪い例: `Claude Code Actionを使ってPRのCode Suggestionをしてもらう`
  - 句読点の前後は詰める。インラインコードの前後にはスペースを入れる

## 残すもの

文体を澄ませることと、内容を無味乾燥にすることは別に扱う。次の 3 つは p1ass の記事の核として残す。

- **余談と脱線**。「余談ですが」「ちなみに」で本筋から外れた補足を挟む
- **率直な自己開示**。失敗、判断の誤り、自分のバイアスの自覚をそのまま書く
- **具体的な数字**。スコア、金額、割合、順位をそのまま出す
  - 例:「結果は 187,577 点で総合 4 位になりました」「前年同期比 38% もの上昇」

## 改行

改行は文法ではなくレンダリング結果で決める。

- 判断基準は「スマホで見たときに文字がびっしり詰まって見えるかどうか」
- 文がだらだら続く前に改行を入れる。1 文が長いときは文の途中で切ってよい
- 段落の切れ目には空行を入れる
- 短い文が続く箇所では、2〜3 文を 1 行にまとめてよい

## 表現

- `**太字**` は本当に大事な要所のみで使う。1 つの記事で数カ所までにとどめる
- 強調するのは、読者が読み飛ばしても拾ってほしい結論や、意外性のある事実
- 強調は本文の中で使い、見出しの役割は見出しに任せる
- 主語が明らかな文では「私は」を省く
- **肯定形で書く**。同じ内容を肯定形で書けるなら、そちらを選ぶ
  - 「テンプレートに囚われない」→「題材に合う流れを優先する」
  - 「〜してはいけない」→「〜を避ける」「〜の対象外とする」
  - 「数字をぼかさない」→「数字をそのまま出す」

## 見出し

- **見出しは名詞句か短い文ひとつで完結させる**。ダッシュやハイフンでサブタイトルを足さない
  - 良い例: `## 残すもの`、`## Honoを採用した理由`、`### ポイント`
  - 悪い例: `## 残すもの — 口語をやめても、これは削らない`
- 補足したいことは見出しではなく、直後の本文に書く
- 締めの見出しは `## おわりに` でそろえる

## 機械的に見える書き方

textlint の `@textlint-ja/preset-ai-writing` が検出する範囲。書きながら意識する。

- 箇条書きを `- **項目**: 説明` の形でそろえる書き方を避け、`- 項目は〜` と地の文で書く
- 「注意」「ポイント」といった語を太字にして行頭に置く書き方を避け、そのまま文を書く
- コロンでコードブロックや箇条書きを導入する英語構文を避ける (`次の通りです:` → `次の通りです。`)
- 絵文字を箇条書きの先頭に置かない

## 避ける表現

- 誇張表現 (`圧倒的に` `劇的に` `革命的な`)
- 理由を示さない断定 (根拠なしの「〜べきです」)
- 中身のない前置き (「〜について説明したいと思います」→「〜を説明します」)
- 同じ文末の 3 連続 (「〜ます。〜ます。〜ます。」)
- 冗長な言い回し (「〜できます」→「〜できます」)
