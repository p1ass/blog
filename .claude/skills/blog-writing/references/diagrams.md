# 図の書き方

記事の図は SVG を手書きして画像として埋め込む方法を第一候補にする。Mermaid は自動レイアウトなので、ループ、キュー、並行する処理、戻りの線を含む図では線が交差したり箱が引き伸ばされたりして、意図した形にならない。Mermaid は、一方向に流れる短いフローやシーケンス図のように、自動レイアウトで崩れない図に限って使う。

## 配置と埋め込み

SVG ファイルを記事と同じディレクトリに置き、ほかの画像と同じく Markdown の画像記法で埋め込む。直後の行にキャプションを置く。

```markdown
![implementer のジョブがキューに並び、isuq が 1 件ずつベンチを回す流れ](./isuq-flow.svg)
_isuq の処理の流れ。ベンチは同時に 1 本しか回せないので、ジョブはキューに並んで順番を待つ_
```

- ルート要素に `width`、`height`、`viewBox` を必ず書く。`rehype-image-size` が `width` と `height` を読んで `<img>` のサイズを決め、Layout Shift を防ぐ
- キャンバスは横幅 1200 を基準にする。記事の本文幅は 760px 程度なので、図は約 0.6 倍に縮んで表示される。縮んでも読めるよう、文字は 16 以上、線は 2 以上にする
- 背景に `<rect width="100%" height="100%" fill="#ffffff"/>` を敷く
- `vite.config.ts` は記事ディレクトリの `.svg` を `dist/` へコピーし、data URI としては埋め込まない。埋め込むと、画像を開くリンクが機能しなくなるため

## 色

色は `app/styles/palette.ts` の値を役割ごとに使う。`<img>` で読み込む SVG はページの CSS 変数を参照できないので、ほかの画像と同じくライトテーマの値で固定する。

| 役割 | パレット |
| --- | --- |
| 背景 | `neutral[0]` |
| グループの枠と塗り | `neutral[200]` の枠、`neutral[50]` の塗り |
| 文字 | `neutral[900]`。矢印のラベルは `neutral[500]` |
| 線と矢印 | `neutral[600]` |
| Agent | `accent[500]` の枠、`accent[50]` の塗り |
| プログラムやシステム | `neutral[0]` の塗りに `neutral[700]` の枠。灰色で塗りつぶすと沈んで見えるので、塗りではなく線で示す。枠の中の箱は `neutral[50]` の塗りに `neutral[300]` の枠 |
| 人間や外から差し込むもの | `warning[600]` の枠、`warning[50]` の塗り |
| 成功、合格 | `tip[600]` の枠と文字、`tip[50]` の塗り |
| 失敗、不合格 | 赤はパレットにないので `neutral[600]`。ラベルの文字で区別する |

同じ種類のものは、図をまたいでも同じ色にする。Agent とプログラムを色で区別したら、記事内のどの図でもその区別を守る。

状態を色だけで表さず、必ずラベルの文字を添える（DESIGN.md の方針）。

## フォント

`<img>` で読み込む SVG はページのフォントを使えないので、各 OS の日本語ゴシック体を順に指定する。

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="1200" height="560" viewBox="0 0 1200 560"
  font-family="'Hiragino Kaku Gothic ProN', 'Hiragino Sans', 'Noto Sans JP', 'Noto Sans CJK JP', 'Yu Gothic', Meiryo, sans-serif">
```

## ラベル

図の文字は構造を読むためだけに置き、説明は本文とキャプションに任せる。

- 箱には担い手の名前だけを書く（「司令塔の Agent」「isuq」）
- 矢印のラベルには、何を渡すか、何をするかを短い動詞句で書く（「タスクを割り当てる」「ジョブを実行する」「レポートを渡す」）
- 判定の条件と分岐（「main の 97% 以上」「合格」「不合格」）は構造そのものなので書く
- 数字や制約は本文に書く

図の中に文章を書き足したくなったら、その内容は本文に移す。説明がないと意味の通らない矢印も、本文で説明するか、図から外す。箱の下の説明行やキャッチコピーを入れた図は、AI が作った図に見える。

## 確認

描いたら必ず画像にして目で確かめる。線と文字の重なり、枠からのはみ出し、余白の偏りを直す。

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
  --hide-scrollbars --window-size=1200,560 --screenshot=/tmp/diagram.png "file://$PWD/diagram.svg"
```

その後、開発サーバーの記事ページで本文幅に縮んだ状態も確認する。
